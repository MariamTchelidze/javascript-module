# 1️⃣ JavaScript in Action

## რა არის JavaScript?

JavaScript არის მაღალი დონის (High-Level), ინტერპრეტირებადი პროგრამირების ენა, რომელიც გამოიყენება ვებგვერდებისთვის ინტერაქტიულობის დასამატებლად.

HTML ქმნის სტრუქტურას.

CSS ქმნის ვიზუალურ დიზაინს.

JavaScript ამატებს ქცევას და ლოგიკას.

---

## რას აკეთებს JavaScript რეალურ სამყაროში?

JavaScript-ის საშუალებით შესაძლებელია:

- ღილაკებზე რეაგირება
- ფორმების შემოწმება
- მენიუების გახსნა
- სლაიდერების შექმნა
- მოდალური ფანჯრების მართვა
- API-დან ინფორმაციის წამოღება
- რეალურ დროში მონაცემების განახლება
- თამაშების შექმნა
- მობილური აპლიკაციების შექმნა
- სერვერული პროგრამების შექმნა

---

## თანამედროვე JavaScript

დღეს JavaScript აღარ არის მხოლოდ Browser-ის ენა.

მისი გამოყენება შესაძლებელია:

### Front-End Development

მომხმარებლის ინტერფეისის შესაქმნელად.

### Back-End Development

სერვერული ლოგიკის დასაწერად.

### Mobile Development

Android და iOS აპლიკაციების შესაქმნელად.

### Desktop Development

Windows, Linux და macOS პროგრამების შესაქმნელად.

### Game Development

2D და 3D თამაშებისთვის.

### AI Tools

AI ინტერფეისებისა და ხელსაწყოების შესაქმნელად.

# 2️⃣ How Programming Works

## რა არის პროგრამირება?

პროგრამირება არის კომპიუტერისთვის ინსტრუქციების მიწოდების პროცესი.

კომპიუტერს არ შეუძლია აზროვნება.

ის მხოლოდ ასრულებს ბრძანებებს.

---

## პროგრამის მთავარი იდეა

ნებისმიერი პროგრამა შედგება:

### Input

ინფორმაცია, რომელსაც იღებს პროგრამა.

### Processing

ინფორმაციის დამუშავება.

### Output

საბოლოო შედეგი.

---

## კომპიუტერის მუშაობის მოდელი

ყველა პროგრამა მუშაობს შემდეგი სქემით:

Input → Processing → Output

ეს არის პროგრამირების ფუნდამენტური პრინციპი.

---

## ალგორითმი

ალგორითმი წარმოადგენს ნაბიჯ-ნაბიჯ ინსტრუქციების ერთობლიობას.

კარგი პროგრამისტი პირველ რიგში ალგორითმულად აზროვნებს.

შემდეგ წერს კოდს.

---

## პრობლემების გადაჭრის პროცესი

პროგრამირება რეალურად არის პრობლემების გადაჭრა.

პროფესიონალი დეველოპერები დროის დიდ ნაწილს კოდის წერაში კი არა, პრობლემების ანალიზში ატარებენ.

---

# 3️⃣ How JavaScript Works

## JavaScript Engine

JavaScript კოდი პირდაპირ არ სრულდება.

მას ამუშავებს სპეციალური პროგრამა, რომელსაც JavaScript Engine ეწოდება.

---

## Engine-ის მთავარი ამოცანები

- კოდის წაკითხვა
- ანალიზი
- ოპტიმიზაცია
- შესრულება

---

## Parsing

პირველი ეტაპია Parsing.

ამ დროს ძრავი ამოწმებს:

- სინტაქსს
- სტრუქტურას
- შეცდომებს

---

## Compilation

თანამედროვე JavaScript ძრავები იყენებენ Just-In-Time Compilation-ს.

ეს ნიშნავს:

კოდი შესრულების პროცესშივე ოპტიმიზირდება.

---

## Execution

ამის შემდეგ კოდი სრულდება.

---

## Call Stack

JavaScript იყენებს Call Stack-ს.

Call Stack არის მექანიზმი, რომელიც აკონტროლებს:

- რომელი ფუნქცია სრულდება
- რომელი ფუნქცია უნდა შესრულდეს შემდეგ

---

## Memory Heap

Heap არის მეხსიერების ნაწილი, სადაც ინახება:

- ობიექტები
- მასივები
- კომპლექსური მონაცემები

---

# 4️⃣ Dynamic vs Weakly Typed Languages

## რა არის Dynamic Typing?

JavaScript დინამიურად ტიპიზირებული ენაა.

ეს ნიშნავს:

ცვლადის ტიპის წინასწარ განსაზღვრა საჭირო არ არის.

ტიპი განისაზღვრება შესრულების დროს.

---

## რა არის Weak Typing?

Weak Typing ნიშნავს, რომ JavaScript გარკვეულ სიტუაციებში ავტომატურად გარდაქმნის მონაცემთა ტიპებს.

---

## Type Coercion

Type Coercion არის ავტომატური ტიპური გარდაქმნა.

ეს JavaScript-ის ერთ-ერთი ყველაზე მნიშვნელოვანი და ხშირად გაუგებარი მექანიზმია.

---

## უპირატესობები

✅ სწრაფი განვითარება

✅ ნაკლები კოდი

✅ მეტი მოქნილობა

---

## ნაკლოვანებები

❌ მოულოდნელი შედეგები

❌ რთული Debugging

❌ დამწყებებისთვის დამაბნეველი ქცევები
