# Practice Exercises – Introduction to JavaScript

## Exercise 1: JavaScript Around You

### Difficulty

🟢 Junior

### Task

Visit 3 different websites and identify features powered by JavaScript.

Examples:

- Navigation menus
- Dark mode toggles
- Image sliders
- Form validation
- Search functionality

### Requirements

Write down:

- Website name
- JavaScript feature
- What happens when the user interacts with it

💡 Hint

Think about anything on a website that changes without reloading the page.
