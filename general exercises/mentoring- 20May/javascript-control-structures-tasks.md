# JavaScript Control Structures — პრაქტიკული დავალებები

ეს დავალებები დაგეხმარებათ JavaScript-ში **control structures**-ის უკეთ გაგებაში.

თემები:

- `if / else`
- comparison operators
- logical operators
- `switch`
- `for` loop
- `while` loop
- `break`
- `continue`
- nested conditions
- პატარა პრაქტიკული ლოგიკის აწყობა

დავალებები დალაგებულია მარტივიდან შედარებით რთულისკენ.

# მთავარი იდეა

Control structures გვეხმარება ვმართოთ პროგრამის ნაკადი.

ანუ ვეუბნებით პროგრამას:

- **როდის** უნდა შესრულდეს კოდი
- **რამდენჯერ** უნდა შესრულდეს კოდი
- **როდის** უნდა გაჩერდეს
- **რომელი გზა** უნდა აირჩიოს სხვადასხვა პირობებში
